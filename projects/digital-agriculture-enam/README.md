# Digital agriculture in India: e-NAM indicators

**Download:** [State/UT trade data](data/enam_state_trade_since_inception_2025-06-30.csv) · [State/UT farmer registrations](data/enam_farmers_registered_2025-06-30.csv)

This project organises two Government of India e-NAM tables into CSV files, preserving the published snapshot date of **30 June 2025**. The trade file covers 27 States/UTs and reports markets integrated plus cumulative trade quantity and value since platform inception. The registrations file reports registered farmers by State/UT.

**National context at the same date:** 1,522 mandis; 17,941,613 registered farmers; 267,719 traders; 4,518 FPOs; 116,042 commission agents; cumulative trade value ₹439,940.97 crore. Countable commodity units are recorded separately from metric tonnes.

## Read carefully

- These are cumulative platform totals, not annual flows or measures of farmer income, welfare, adoption, or active use.
- Registrations are not the same as unique active farmers or farmers who traded.
- A dash in the source table means no value was reported; it is kept as an empty CSV field. Do not treat it as zero.
- Some reported market or volume values can look unusual; values are transcribed as published and should be checked against the source before substantive analysis.
- This is a first e-NAM module, not a comprehensive dataset of all agricultural digitalisation programmes.
